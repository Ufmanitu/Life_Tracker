# Life_Tracker
All in one life tracker that saves the changes to your local storage and operates offline. Contains:

Habit tracker with analysis and statistics;
 
Calendar and timetable with import feature from Google Calendar; 

Event tracker with daily, weekly, monthly and yearly scopes;

Shopping list;

Pomodoro timer for studying;

Mentrual cycle tracker and birth controll pill tracker for women. 

Has multiple colorful themes and is available in 5 lenguages (English, Deutsch, Spanish, French and Hungarian).

Responsive: works on a scale of devices, but for BEST experience use laptop or big screen.
